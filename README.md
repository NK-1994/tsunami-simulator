# 🌊 津波防災シミュレーター

ブラウザ上で動作する津波シミュレーターです。
防波堤を自由に配置して、津波の減衰効果を体験的に学ぶことができます。
中学・高校の防災教育での利用を想定しています。

## 🔗 公開URL

https://nk-1994.github.io/tsunami-simulator

## 🎮 使い方

1. **防波堤を配置する**
   - 左パネルで防波堤（1〜5基）を選択
   - 画面上をクリック・ドラッグして配置
   - iPad はタッチ操作に対応

2. **シミュレーションを実行する**
   - 「▶ RUN」ボタンを押す
   - 波の振幅・水深はスライダーで調整可能

3. **結果を確認する**
   - 3Dアニメーションで波の伝播を確認
   - 「📊 結果を表示」で減衰率・到達時刻を確認

## ⚙️ 物理モデル

- **支配方程式**：2次元線形浅水方程式（Linear SWE）
- **数値手法**：有限差分法（Arakawa C格子）
- **安定条件**：CFL = 0.4
- **初期条件**：ガウシアン型波源
